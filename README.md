# Проект: API тестирование с использованием Cucumber и Allure

### Задачи проекта

#### Погружение в API Rick and Morty

* Поиск информации о персонаже Морти Смит
* Получение последнего эпизода с участием Морти
* Извлечение последнего персонажа из этого эпизода
* Сравнение характеристик персонажей (раса, локация)

#### Тестирование REST API
* Регистрация пользователя
* Авторизация (успешная и с ошибками)
* Выход из системы
* Работа с JSON файлами и токенами

##### Запуск тестов

Запуск всех тестов:
* mvn clean test

Запуск локального сервера с отчетом:
* mvn allure:serve

Сгенерировать отчет:
* mvn allure:report
