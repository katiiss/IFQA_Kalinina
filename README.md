## Автоматизированные тесты, которые были реализованы для проверки создания и управления задачами в системе Jira:
- Авторизация в системе
- Создание задач
- Переход по задачам
- Изменение статусов задач
- Проверка отображения количества задач

## Технологии

- **Java 17**
- **Selenide** - для автоматизации браузера
- **JUnit 5** - фреймворк для тестов
- **Allure** - для отчетов
- **Maven** - для сборки проекта

## Запуск тестов
* Запуск всех тестов:

_mvn clean test_

* Запуск локального сервера с отчетом:

_mvn allure:serve_

* Сгенерировать отчет:

_mvn allure:report_
